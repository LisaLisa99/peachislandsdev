# Peach Islands Shopify Theme

Online Store 2.0 conversion of the supplied Peach Islands HTML website, on branch `peach-islands-html-conversion`. The original logo and all 55 supplied images are included unchanged. This branch is independent of `main` and `peach-islands-starter`.

The homepage is composed of reusable, reorderable sections: split image hero, image/text columns (three independently configured instances), editorial story, newsletter, and spacing. Native Liquid product/collection/cart templates use Shopify store data. No Nicepage editor, Nicepage JavaScript, jQuery, or build step is required.

- [Preview safely beside Horizon](THEME-SETUP.md)
- [Design mapping and catalog setup](docs/CONVERSION.md)
- [Validation results and reproducible checks](docs/VALIDATION.md)

No files have been uploaded to Shopify and no theme has been published. Hosted Shopify rendering and checkout still require validation in an unpublished theme.
